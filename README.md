# 个人网站维护

网站由 GitHub Pages 从 `master` 分支的仓库根目录构建。

| 内容 | 修改文件 |
| --- | --- |
| 首页、工作经历、开源项目 | `index.md` |
| 教育经历 | `pages/education.md` |
| 所获荣誉 | `pages/honors.md` |
| 新闻报道 | `pages/news.md` |
| 发表刊物、专利 | `pages/publications.md` |
| 导航、站点信息 | `_config.yml` |

以上文件是各页面的维护入口，不再保留或创建第二套内容副本。更新后提交并推送，等待 GitHub Pages 部署成功，再检查对应线上页面。

旧 Markdown 副本及未上线的项目简记保存在 Git 历史中，可在提交 `91dca7b` 查看。
